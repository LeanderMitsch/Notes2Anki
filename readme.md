# Notes2Anki

## The Problem

Creating Anki decks can become tiresome quickly, if you have to type out many formulas or mathematical expressions. This project offers a solution, by providing a PDF template with a grid (generated by the `create_template.py` script), which can be filled out with content that you want to put inside an Anki deck. 

<img src="/readme_images/Example_page.png" alt="Example page" width="500"/>

## HowTo

1. Import the template into your writing device of choice (iPad, reMarkable, Samsung Tablet, etc.)
2. Fill out the flashcard grid
3. Export the file again as a PDF to the `/input` folder
4. Run the `process_pdfs.sh` bash script to generate Anki decks from all PDFs placed in the input folder

If you are not using Linux/macOS, you can create a venv, install all dependencies from the `requirements.txt` file, and run the script manually by executing `python slice_flashcards.py {inputpdf.pdf}`. In this case, you have to go through this step for each PDF you want to slice manually.

Flashcards can then be imported in the mobile or desktop application by choosing the `.apkg` file.

I provided some examples in the `input` directory, with their respective output in the `output` directory.
